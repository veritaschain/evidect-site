# 公開された再現案内の実HTTP照合

このツールは、GitHub Pagesの配信ジョブ成功と、実際のHTTPS応答の確認を分けます。
指定したGitコミットの6ファイルと公開応答の**元のバイト列**を比較します。
VAP/VCPの証拠検証、ブラウザ描画、セキュリティ審査、外部組織による再現ではありません。
規制調査メモ、本番AILEX、顧客データ、署名鍵には触れません。

## 実行

レビューしたこのリポジトリのチェックアウトで、Linux/macOSとPython 3.10以上を使用します。
追加パッケージは不要です。指定コミットのGitオブジェクトがローカルに必要です。
公開ページの取得にはネットワークを使います。

```sh
python3 -I -B tools/site-verification/test_probe.py -v
python3 -I -B tools/site-verification/probe.py \
  --expected-commit 33ec924074f4907bff2336c09e2db877cb1fc3f6 \
  --output ./new-public-observation.json
```

上のコミットはPR #15の配信元です。後の配信を調べる場合は、確認する配信元の
40桁コミットへ明示的に変更します。作業ツリーを基準にせず、`git cat-file`でその版を読みます。
ハッシュを指定すること自体はソースの真正性や署名者の身元の証明ではありません。
出力先は未存在、親ディレクトリは自分で保護する場所を指定してください。

## 対象と結果

対象は `https://evidect.veritaschain.org` の次の6件に固定されています。

- `/methodology/`
- `/assets/css/evidect-site.css`
- `/assets/css/seo-navigation.css`
- `/assets/css/reproduction.css`
- `/assets/js/evidect-site.js`
- `/sitemap.xml`

| 結果 | 終了コード | 意味 |
| --- | --- | --- |
| MATCH | 0 | 6件すべてがHTTP 200、期待する種類の応答で、指定版のバイト列と一致 |
| MISMATCH | 1 | 取得できた応答のうち少なくとも1件でバイト不一致を観測 |
| UNVERIFIED | 2 | 不一致は確認していないが、通信・HTTP・形式などの理由で全件を確認できない |
| 標準エラーのみ | 2 | ソース、引数、出力先などが不正。成功報告を作らない |

既知の不一致と別項目の取得不能が重なればMISMATCHを優先し、個別理由も残します。
HTTP 200だけでは成功にせず、取得不能時にローカルファイルへ置き換えません。
保存済みの成功記録を再利用せず、毎回新しい出力先を使います。出力は0600で排他作成します。

元の本文やCookieは出力せず、観測時刻、応答状態、サイズ、SHA-256、ソースコミット、
検査スクリプト自身のSHA-256を記録します。報告は未署名で編集可能な観測結果です。
検査時点・その実行環境から得られた6応答の確認に限られ、継続可用性や全地域での配信一致は保証しません。

## 通信・CIの範囲

GETのみ、対象ホスト・パス固定、リダイレクトは追跡せず、認証情報・Cookieを送りません。
Python標準のHTTPS証明書・ホスト名検査を無効化しません。ブラウザを偽装せず、ツール名を送ります。
HTTPプロキシ環境変数は使用しません。各本文は最大1 MiB。接続・読み取りのタイムアウトを設定し、
本文の読み取りには経過時間チェックもあります。DNSやOSの停止まで含む厳密な総実行期限ではなく、
GitHubのジョブ全体には別途5分の上限を設けています。1回につき最大6リクエストで自動リトライしません。

CIは新規検査コードのPRでオフライン単体テストと既存サイトテストを実行します。
同一リポジトリ内のPRでは公開サイトを**PRのbaseコミット**と照合します。PRの未配信内容とは比較しません。
Pagesのmain配信成功後は、`workflow_run`の配信元コミットと照合します。
手動実行はmainに限定し、明示したコミットまたはそのmain版を使います。
`contents: read`のみ、checkout認証を保存せず、秘密情報・非公開成果物・キャッシュを使用しません。
他リポジトリのPRから公開照合を起動しません。定期実行や外部への通知・投稿は追加しません。
CI成果物は観測JSONと環境情報のみ、30日保存です。

配信更新が同時に発生した場合やCDN反映が遅い場合も、不一致を成功に変換しません。
配信履歴を確認して、意図したコミットで手動再実行してください。

## 確認しないこと

HTMLの描画、操作、アクセシビリティ、リンク先GitHubのIssue入力・送信はこの検査では確認しません。
ソースに含まれる自己申告・規制上の説明が正しいかも別の検査です。
管理策の有効性、独立再現、外部アンカー、認証、法令適合の実績を増やす処理ではありません。
